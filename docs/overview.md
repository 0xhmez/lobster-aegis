# Overview

## Project name
Lobster Aegis 2.0 — Intent-Driven Wallet Threat Response Agent on OKX Onchain OS

## Chinese title
龙虾神盾 2.0——基于 OKX Onchain OS 的意图驱动链上威胁响应执行体

## What problem does it solve?
In Web3, many losses occur not because users never receive warnings, but because they cannot react fast enough after dangerous authorization or wallet threat exposure has already happened.

Lobster Aegis 2.0 addresses this execution gap.

## What is the core idea?
Transform threat intent into machine-executable defensive response.

## What is the demo scope?
A suspicious high-value stablecoin approve event is detected, analyzed, compiled into a rescue order, and responded to with `REVOKE_APPROVAL`.

## What is the system boundary?
Claw is constrained to classification and parameter extraction.
Execution is controlled by schema validation and state-machine-driven response logic.
