# Reproducibility

## Workflow-level reproducibility
This repository demonstrates a reproducible threat response workflow rather than a vague security concept.

A reviewer can inspect:
- how a suspicious event is represented
- how Claw outputs a threat summary
- how a rescue order is built
- how the state machine controls response paths
- how audit logs are generated

## Reproduction path
1. Read README.md
2. Read docs/architecture.md
3. Review prompts/
4. Review schemas/
5. Review mock-data/
6. Run the minimal workflow in src/
7. Compare the output with screenshots and videos
