# Scoring Alignment

## 1. Integration
Lobster Aegis 2.0 uses OKX Onchain OS as the execution operating layer for wallet threat response.

Claw is used as a constrained threat-intent compiler rather than as a generic assistant.

## 2. Utility
The project solves a real Web3 problem:
human reaction is often too slow once dangerous authorization or wallet threat exposure has already happened.

## 3. Innovation
Most wallet security tools stop at alerting users.
Lobster Aegis 2.0 turns threat detection into structured defensive execution.

## 4. Reproducibility
The repository includes:
- prompts
- schemas
- mock threat events
- rescue order examples
- state machine logic
- demo assets
- audit examples

This makes the project reproducible at the workflow level.
