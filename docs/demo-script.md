# Demo Script

## Scenario
A suspicious high-value approve event is detected for USDC exposure.

## Sequence
1. Monitoring status
2. Threat detected
3. Threat summary output
4. Rescue order built
5. Response executed
6. Safe state restored
7. Audit log generated

## Key fields to highlight
- threat_level: critical
- estimated_exposure: 10000 USDC
- recommended_action: REVOKE_APPROVAL
- execution_priority: immediate
- proof_type: Proof of Defense
